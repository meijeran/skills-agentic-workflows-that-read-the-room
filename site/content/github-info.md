## Recent updates worth watching (August 2026)

- **Trigger Copilot automations with comments** — you can now kick off Copilot agent automations directly from an issue or PR comment, making it easier to hand off follow-up work without leaving the conversation. (Source: GitHub Changelog)
- **Copilot Code Review effort levels are generally available** — teams can tune how thorough Copilot's automated code review passes are, balancing speed against depth of feedback. (Source: GitHub Changelog)
- **Agent Plugins 1.0** — a new plugin system for extending Copilot agents is now available across VS Code, the Copilot CLI, and the Copilot app, letting developers add custom tools and behaviors. (Source: GitHub Changelog)
- **The new GitHub Copilot experience in Slack** and **shared agentic work with Copilot in Microsoft Teams** — Copilot agent sessions can now be started and followed from chat tools your team already uses. (Source: GitHub Changelog)
- **Copilot memory and Ollama support in GitHub Copilot for JetBrains** — JetBrains users get persistent Copilot memory plus the option to run local models via Ollama. (Source: GitHub Changelog)
- **"The harness is all you need, mostly"** and **"How canvases make agentic workflows visible, steerable, and cost-efficient"** — two GitHub Blog posts on designing dependable agentic coding workflows, useful background reading alongside the Changelog items above. (Source: GitHub Blog)
- **"From coder to orchestrator: how agents shift the role of a developer"** — a GitHub Blog piece on how day-to-day developer work changes as AI agents take on more implementation tasks. (Source: GitHub Blog)
